Input → This is where you give instructions/data to the computer

Example: Keyboard, mouse, microphone

Central Processing Unit (CPU) → The CPU has 3 main parts

- Memory unit → Stores small, temporary data the CPU is actively using

- Control unit (CU) → It's like the "manager", it controls the flow of data between the CPU, memory and input/output

 - Arithmetic Logic Unit (ALU) → As the name suggests, it handles both Arithmetic (+, -, ÷, **×**) and Logic [comparisons (>, <, =) and true/false decisions]

Main Memory → Basically RAM, it holds data/programs that are currently being used and is temporary

Secondary Storage → This is your SSD/HDD, it stores your files permanently.

Output unit →This is where the results appear

Example: Monitor, printer, speakers

## Language Translators

**System Software** - It manages and controls computer hardware, provides a platform for running application software, and acts as a bridge between user-written programs and the hardware.

**Compilers**

A compiler is a program that translates an entire high-level language program into machine code in one go, producing an executable file that can be run without a compiler.

Example: C/C++/C#/Fortran language is compiled

**Interpreter**

An interpreter reads a high-level program one instruction (or line) at a time, translates it into machine code, and executes it immediately.

This process is repeated for each instruction in the program until the program finishes running.

Unlike a compiler, an interpreter does not produce a separate executable file. Instead, it translates and runs the program directly each time it is executed.

Example: Programs written in Python language are interpreted

## Why python

Python is a multi-purpose language with a simple, and beginner friendly syntax, created by Guido van Rossum and is first released in 1991.

- Python is a multi-platform and open source language.
- Many libraries, modules, and projects focused on computer security are written in Python.
- A lot of documentation is available, along with a very large user community.
- Ideal for prototypes and rapid-concept tests.
- Object oriented programing allows you to structure programs using objects and classes
   - You can group data and function together into "objects"
   - Helps organize large programs and make code reusable
- Database manipulation
   - Python can connect to and work with databases.
      - Read data (SELECT)
      - Insert data (INSERT)
      - Update or delete records
      - E.g. Using python to store user information in a database like SQLite or MySQL
- Graphical User Interface (GUI) Programming
      - Python can be used to create applications with:
         1. Windows
         2. Buttons
         3. Menus
         4. Input Fields
         - Example: Building a simple calculator app with buttons instead of typing commands
- Integrate easily with C/C++ and is lightweight
      - This means Python can:
         1. Work together with C/C++ codes
         2. Use C/C++ for faster performance when needed
      - "Lightweight" here usually means:
         1. Python itself is simple and not bulky
         2. Easy to extend with faster languages
         - Example: Heavy calculations done in C, while Python handles the main program

### Flowchart

Why and what is a flowchart

- Structured steps help simplify processes.
- Flowcharts visually represent logic clearly
- A flowchart is a visual representation of the steps involved in problem solving.

Benefits of using a flowchart

1. Clarity
   - Flowcharts offer a clear and visual representation of processes, effectively eliminating ambiguity and confusion
1. Efficiency
   - By mapping out processes, you can identify bottlenecks and areas of improvement. This leads to streamlined workflows.
1. Communication
   - Flowcharts serve as a universal language for teams, facilitating better understanding between departments.

Tips for an effective flowchart:

1. Keep it simple

3. Be consistent
   - Keep shapes and sizes the same throughout
4. Review and refine
   - Update the flowcharts regularly to show changes and improvements
