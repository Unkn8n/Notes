## Language Translators

**System Software** - It manages and controls computer hardware, provides a platform for running application software, and acts as a bridge between user-written programs and the hardware.

**Compilers**

A compiler is a program that translates an entire high-level language program into machine code in one go, producing an executable file that can be run without a compiler.

Example: C/C++/C#/Fortran language is compiled

**Interpreter**

An interpreter reads a high-level program one instruction (or line) at a time, translates it into machine code, and executes it immediately.

This process is repeated for each instruction in the program until the program finishes running.

Unlike a compiler, an interpreter does not produce a separate executable file. Instead, it translates and runs the program directly each time it is executed.

Example: Programs written in Python language are interpreted
