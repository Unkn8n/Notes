# Domain and Range

**Domain**

> The **domain** of a function is the set of all values (inputs) of the independent variables for which the function is defined. If x is in the domain of $f, f$ is said to be *defined* at $x$.

> If $x$ is not in the domain of $f, f$ is said to be *undefined* at $x$.

If a function is defined by a rule relating $x$ to $f(x)$ without specific mention of its domain, it is understood that the domain will consist of all values of $x$ for which $f(x)$ is a real number. In this connection, keep in mind:

1. Division by zero is not permitted $(x/0)$
2. the square root of a negative number is not defined $(√−𝑥)$

The domain of $f$(𝑥) = 3𝑥 + 5 is all real number. For $*g*(x) = 1/x$ , since $g(x)$ is undefined only when $x = 0$, then the domain of $g(x), D(g) = {x ≠ 0}.$

**Range**

The range of a function consists of all the values assumed by $y = 𝑓(x)$.

> The **range** of a function is the set of all values (outputs) assumed by the dependent variable (that is, the set of all function values).

a) $𝑓(x) = 2x + 1$

- In $2x + 1$, you can multiply any number by 2 and add 1 without any issues.
- Whether $x$ is zero or a negative fraction the equation will still work
- As $f(x) = 2x + 1$ is a linear equation, the line will be continuous and won't stop.

$D(f) = {x: x ∈ ℝ}$ or all real numbers

{} represents a set, the first $x$ tell you what the variable is, the colon is read as such that, $x ∈ ℝ$ means that $x$ is an element of the real numbers.

This is basically saying that "The set of $x$, such that $x$ is an element of the real numbers."

$R(𝑓) = {𝑓(x): 𝑓(x) ∈ ℝ}$ or all real numbers

Remember that $f(x)$ is $y$ and it'll make sense



b) $f(x) = 1/x$

- For $x$, it can't be 0 as a division by zero is not permitted.
- As the top number is a constant (1), the result of the fraction can never be 0.

$D(𝑓) = {x ∈ ℝ: x ≠ 0}$ or all real numbers except zero

Again the braces represents a set, $x$ is the variable and ∈ ℝ tells you that the variable is in an element of the real numbers. The colon is such as and  $x ≠ 0$ is telling you that x does not equal to 0.

So, it can be read as "The set of $x$ is an element of the real numbers such that $x$ is not equal to 0.

$R(𝑓) = {𝑓(x) ∈ ℝ: 𝑓(x) ≠ 0}$ or all real numbers except zero

I think you get how to interpret this.



c) $𝑓(x) = √(x − 1)$

- $x$ has to be more than or equal to 1 else your calculator will give an "error"
- $f(x)$ will be 0 if x were 1 and since 1 is the lowest number that $x$ can be, $f(x)$ has to be more than or equal to 0

$D(𝑓) = {x ∈ ℝ: x ≥ 1}$

$R(𝑓) = {𝑓(x) ∈ ℝ: 𝑓(x) ≥ 0}$



d) $𝑓(𝑥) = 3 / √(𝑥−2)$

- $x$ can't be 0 because it'll result in a negative square root which will result in it being a error.
- $√(𝑥−2)$ also can't be zero as division by zero is not permitted.
- Therefore $x$ has to be bigger than 2 to satisfy both conditions.
- $f(x)$ can never be 0 or negative.

$D(𝑓) = {x ∈ ℝ: x > 2}$

$R(𝑓) = {𝑓(x) ∈ ℝ: 𝑓(x) > 0}$
