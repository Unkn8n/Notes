# Concepts of Functions

The idea of correspondence plays an important role in understanding the concept of function.

1. Every **student** has an **admin number**
2. A **single playlist** has **multiple songs** in the playlist
3. **Mary, Steven and Mark** achieved **grade A** for their Mathematics examination

These examples describe a particular correspondence between two groups.

A **relation** is a correspondence between two sets.

The first set is called the **domain** and the corresponding second set is called the **range.**

Members of these sets are called **elements.**

## Definition of Relation

> A **relation** is a correspondence between two sets where each element in the first set, called the **domain**, corresponds to at least one element in the second set, called the **range.**

With the definition of relation, all types of correspondences are considered a relation.

A relation in which each element in the domain corresponds to exactly one element in the range is called a **function**.

**Definition of a Function**

> A **function** is a correspondence between two sets where each element in the first set, called the **domain**, corresponds to *exactly* one element in the second set, called the **range**.

The definition of a function is more restrictive than the definition of a relation. For a relation, each input corresponds to **at least** one output, whereas, for a function, each input corresponds to at **exactly** one output.

**One-to-one** and **many-to-one** correspondences are functions as every element in the domain corresponds to exactly one element in the range.

### Characteristics of a Function

-  Each element in the domain must be matched with an element in the range.
-  Some elements in the range may not be matched with any element in the domain.
-  Two or more elements in the domain may be matched with the same element in the range.
-  An element in the domain cannot be matched with two different elements in the range.



1. {(-3,4),(2,4),(3,5),(6,4)}


   Since no x-value is repeated and each x-value corresponds to one y-value, this relation is a function.


2. {(-3,4),(2,4),(3,5),(2,2)}


   The value x = 2 corresponds to both y = 2 and y = 4. This relation is not a function.


3. Domain = Set of all items for sale in a grocery store; Range = Price


   Each item in the grocery store corresponds to exactly one price. This relation is a function.
