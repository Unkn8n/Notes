# Functions Defined by Equations

A function is a rule that assigns exactly one output to each input. Functions are often defined by equations, which provides a clear way to describe the relationship between the input (usually x) and the output (usually y).

---

For equation $y = x^2 - 3x$, where $x$ can be any real number. This equation assigns to each $x$-value exactly one corresponding y-value.

![image.png](Interpreting%20Functions.assets/image%20(4).png)

![image.png](Interpreting%20Functions.assets/image%20(5).png)

This is a one-to-one correspondence, therefore, the equation $y = x^2 - 3x$ defines a function.

---

Since the variable y depends on what value of x is selected, we denote y as the dependent variable. The variable $x$ can be any number in the domain; therefore, we denote $x$ as the independent variable.

While many functions are defined by equations, not all equations satisfy the requirement of being a function: that for every input $(x)$, there is exactly one output $(y)$.
