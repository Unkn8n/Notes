#### Concepts of Functions

The idea of correspondence plays an important role in understanding the concept of function.

1. Every **student** has an **admin number**
2. A **single playlist** has **multiple songs** in the playlist
3. **Mary, Steven and Mark** achieved **grade A** for their Mathematics examination

These examples describe a particular correspondence between two groups.

A **relation** is a correspondence between two sets.

The first set is called the **domain** and the corresponding second set is called the **range.**

Members of these sets are called **elements.**

### Definition of Relation

> A **relation** is a correspondence between two sets where each element in the first set, called the **domain**, corresponds to at least one element in the second set, called the **range.**

With the definition of relation, all types of correspondences are considered a relation.

A relation in which each element in the domain corresponds to exactly one element in the range is called a **function**.

**Definition of a Function**

> A **function** is a correspondence between two sets where each element in the first set, called the **domain**, corresponds to *exactly* one element in the second set, called the **range**.

The definition of a function is more restrictive than the definition of a relation. For a relation, each input corresponds to **at least** one output, whereas, for a function, each input corresponds to at **exactly** one output.

**One-to-one** and **many-to-one** correspondences are functions as every element in the domain corresponds to exactly one element in the range.

### Characteristics of a Function

- > Each element in the domain must be matched with an element in the range.
- > Some elements in the range may not be matched with any element in the domain.
- > Two or more elements in the domain may be matched with the same element in the range.
- > An element in the domain cannot be matched with two different elements in the range.



1. {(-3,4),(2,4),(3,5),(6,4)}

   Since no x-value is repeated and each x-value corresponds to one y-value, this relation is a function.

2. {(-3,4),(2,4),(3,5),(2,2)}

   The value x = 2 corresponds to both y = 2 and y = 4. This relation is not a function.

3. Domain = Set of all items for sale in a grocery store; Range = Price

   Each item in the grocery store corresponds to exactly one price. This relation is a function.

### Functions Defined by Equations

A function is a rule that assigns exactly one output to each input. Functions are often defined by equations, which provides a clear way to describe the relationship between the input (usually x) and the output (usually y).

---

For equation y = x^2 - 3x, where x can be any real number. This equation assigns to each x-value exactly one corresponding y-value.

![image.png](Interpreting%20Functions.assets/image%20(4).png)

![image.png](Interpreting%20Functions.assets/image%20(5).png)

This is a one-to-one correspondence, therefore, the equation y = x^2 - 3x defines a function.

---

Since the variable y depends on what value of x is selected, we denote y as the dependent variable. The variable x can be any number in the domain; therefore, we denote x as the independent variable.

While many functions are defined by equations, not all equations satisfy the requirement of being a function: that for every input (x), there is exactly one output (y).

### Function Notation

Equation y = 2x + 5 is a function as we can select any x-values (input) and determine unique corresponding y-values (output). The output is found by taking 2 times the input and then adding 5. If the function's name is “*f*”, then we can use **function notation:**

> *f*(x) = 2x + 5

*f*(x) is read as "*f* evaluated at x" or "*f* of x" and represents the y-value that corresponds to a particular x-value. In other word, y = *f*(x).

| Input                    | Function      | Output                      | Equation                            |
| ------------------------ | ------------- | --------------------------- | ----------------------------------- |
| x (Independent variable) | *f (Mapping)* | *f*(x) (Dependent variable) | *f*(x) = 2x + 5 (Mathematical rule) |

*f* is the function name while *f*(x) is the value of the function.

The function *f* maps some value of x in the domain to some value of x in the domain to some value *f*(x) in the range.

### Domain and Range

**Domain**

> The **domain** of a function is the set of all values (inputs) of the independent variables for which the function is defined. If x is in the domain of *f*, *f* is said to be *defined* at x.

> If x is not in the domain of *f, f* is said to be *undefined* at x.

If a function is defined by a rule relating x to *f*(x) without specific mention of its domain, it is understood that the domain will consist of all values of x for which *f*(x) is a real number. In this connection, keep in mind:

1. Division by zero is not permitted (x/0)
2. the square root of a negative number is not defined (√−𝑥)

The domain of 𝑓(𝑥) = 3𝑥 + 5 is all real number. For *g*(x) = 1/x , since *g*(x) is undefined only when x = 0, then the domain of *g*(x), D(*g*) = {x ≠ 0}.

**Range**

The range of a function consists of all the values assumed by y = 𝑓(x).

> The **range** of a function is the set of all values (outputs) assumed by the dependent variable (that is, the set of all function values).
